1. 为什么这是一个极高价值的严肃商业机会？

          

            私家团、高定旅行、亲友包车自驾与户外俱乐部是旅游行业客单价最高（人均 ¥10,000–¥80,000+）、复购与口碑传播最强的细分市场。但即使收费数万元的高定团，交付给客人的依然是一份静态 PDF 路书或零散的微信群通知。
          

          
    
            
  • 痛点 1（野外断网失联）：在巴塔哥尼亚 Fitz Roy 步道、梅里雨崩或南极洛 3950m 湖区，手机信号归零，在线小程序或未缓存网页直接白屏。
    • 
            
  • 痛点 2（群聊信息熵增）：集合时间、14:30 出发红线、酒店定位、Plan A/B 投票淹没在几百条群消息里。
    • 
            
  • 痛点 3（国内外网络割裂）：海外工具（Wanderlog/Google My Maps）在国内无法打开；国内模板工具缺乏徒步海拔、机位时刻与离线预编译能力。
    •

Stage 1 · 极简日程解析器 (Raw Agenda Parser)

          
支持自然语言多行文本或 JSON 输入，自动识别：

          
    
            
  • 日期跨度与单日/多日合并段（如 D1 11/21、D6-D9 11/26-11/29）
    • 
            
  • 住宿锚点（宿丽江、宿飞来寺、宿同乐村）
    • 
            
  • 刚性时间约束（如 14:30之前从香格里拉出发）并升级为红色安全预警横幅
    • 
            
  • 未决分叉路线（方案A 雨崩 vs 方案B 南极洛）并编译为前端交互状态机
    • 
          

        


        

          
Stage 2 · 地理空间与在地向导增强 (Geo & Guide Enricher)

          
把孤立的地名扩展为“自己去旅行时真正需要的一切实战信息”：

          
    
            
  • 双坐标系预计算：同时输出 WGS-84 与 GCJ-02 火星坐标，消除国内高德底图偏移。
    • 
            
  • 途经点自动补全：不仅标出终点酒店，还把沿途必停的虎跳峡、白水台、松赞林寺、白马雪山垭口、茨中教堂全部预标在地图上。
    • 
            
  • 向导级颗粒度：最佳机位时刻、高反洗头禁忌、晕车弯道提醒、必点在地美食全部内联编译。
    • 
          

        


        

          
Stage 3 · 国内外双栈网络适配器 (Region-Adaptive Stack)

          
    
            
  • cn_domestic（中国境内零阻碍栈）：
              底图采用高德 webrd0{1-4}.is.autonavi.com；导航采用高德 uri.amap.com 与百度地图 URI；知识与攻略全部指向百度百科、小红书搜索、携程目的地；前端库走国内 cdn.staticfile.net。
    • 
            
  • global（海外全球标准栈）：
              底图采用 Carto Voyager / OSM；导航采用 Google Maps Universal Link；知识采用 Wikipedia / AllTrails / TripAdvisor；支持 KML 离线轨迹下载。
    • 
          

        


        

          
Stage 4 · 离线 PWA 预编译与 GitHub 发布器 (`generator.py`)

          
已实装于 ~/.travel_studio/generator.py，支持三大子命令：

          
# 1. 从原始文本编译离线 PWA 包
python3 generator.py compile \
  --input agenda.txt \
  --region cn_domestic \
  --title "云南 2026 私家团" \
  --output ./dist

# 2. 为现有项目注入 Service Worker 离线引擎
python3 generator.py inject-offline \
  --dir ~/.south_america_2026 \
  --title "South America 2026"

# 3. 一键发布上线至 GitHub Pages
python3 generator.py publish \
  --dir ./dist \
  --repo YoungApple/yunnan-2026
